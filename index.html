THE WHOLE “PARADOX”

Rolling contribution + turning reference frame

N_lab = (R + r) / r = R/r + 1 N_radial = R / r C_center = 2π(R + r)

For equal circles, the rolling centre travels a circle of radius 2r. Its path length is 4πr, exactly two rolling-coin circumferences.

PARADOX DISCERNMENT

The counts disagree because the frames disagree—not because the geometry does.

The laboratory frame counts the coin against fixed space. The radial frame rotates once with the orbit, so it subtracts one turn. The unwrapped tangent view sees only rolling along the fixed boundary. Each answer is meaningful only after naming its frame.
